# AICodeReviewer

Solution for Prompt Engineering BME-VIK MSc course.

The solution contains:
  -  Source code
  -  The code, which I tested the different prompt techniques on
  -  The output of 5 runs with different prompt techniques

How to run:
  - Checkout the repo
  - Run this command ```streamlit run .\ai_code_review.py```
  - Add your OpenAI API key
